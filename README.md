# Taller Jest - Calculadora de Ventas

**Estudiante:** Marlon Valencia
**Negocio:** Tienda Moda & Estilo
**N = 23**
**Tasa Equipo = (23 mod 5) + 5 = 3 + 5 = 8%**

## Reglas de Negocio
- Menor a 100.000: sin descuento
- Igual o mayor a 100.000: 10% de descuento
- Mayor a 200.000: 10% + 8% tasaEquipo = 18% total
- Validación: solo montos positivos, finitos y numéricos
